# Kexcelled 3D Printing Profiles

Official print profiles for **Kexcelled** 3D printing filaments, pre-configured and optimized for major 3D printers and slicing software. 

This repository is continuously updated with refined parameters to ensure high success rates, exceptional surface finish, and optimal mechanical properties across all Kexcelled product lines.

---

## 📌 Supported Slicers & Ecosystems

Our print profiles are tailored for leading modern slicers:

- **Bambu Studio** / **OrcaSlicer** (`.json`, `.bbsproject`)
- **PrusaSlicer** (`.ini`, `.config`)
- **Cura** (`.curaprofile`)
- **IdeaMaker** (`.bin`)
